============================
  개인 AI 비서 봇 설치 및 실행
============================

[ 1단계 ] 텔레그램 봇 토큰 발급
---------------------------------
1. 텔레그램에서 @BotFather 검색
2. /newbot 입력
3. 봇 이름 입력 (예: 내비서봇)
4. 봇 username 입력 (예: my_secretary_bot) ← 반드시 _bot으로 끝나야 함
5. 발급된 토큰 복사

[ 2단계 ] 내 텔레그램 User ID 확인
---------------------------------
1. 텔레그램에서 @userinfobot 검색
2. /start 입력
3. 표시된 숫자 ID 복사

[ 3단계 ] Anthropic API 키 발급
---------------------------------
1. https://console.anthropic.com 접속
2. 회원가입 후 로그인
3. API Keys 메뉴 → Create Key
4. 키 복사

[ 4단계 ] .env 파일 설정
---------------------------------
이 폴더의 .env 파일을 메모장으로 열고
아래 세 줄을 본인 정보로 수정:

  TELEGRAM_BOT_TOKEN=1234567890:ABCDEF...
  ANTHROPIC_API_KEY=sk-ant-...
  ALLOWED_USER_IDS=123456789

[ 5단계 ] Python 패키지 설치
---------------------------------
이 폴더에서 터미널(PowerShell) 열고 실행:

  pip install -r requirements.txt

[ 6단계 ] 봇 실행
---------------------------------
  python bot.py

============================
  봇 명령어
============================

/start      — 시작 인사
/help       — 명령어 목록
/memo 내용  — 메모 저장
/memos      — 메모 목록 조회
/clear      — 대화 기록 초기화
그 외 텍스트 → AI가 응답

============================
  파일 구조
============================

1.개인비서/
├── bot.py          ← 봇 메인 코드
├── .env            ← API 키 설정 (절대 공유 금지!)
├── requirements.txt
├── logs/           ← 날짜별 대화 로그 자동 저장
└── data/
    └── memos.json  ← 메모 데이터 저장
